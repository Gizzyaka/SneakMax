# 👤 Интернет-магазин SneakMax | пет-проект

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Проект создан для демонстрации профессиональных навыков и опыта в современном цифровом формате.

## ✨ Особенности

- **Адаптивный дизайн** - Корректное отображение на мобильных и десктопных устройствах
- **Интерактивные секции** - Раскрывающиеся блоки с подробной информацией
- **Тёмная/светлая тема** - Поддержка системных предпочтений пользователя
- **Анимации переходов** - Плавные hover-эффекты и анимации прокрутки
- **Локализация** - Поддержка русского и английского языков
